A demo host site

This page belongs to a fictional third-party business. The booking experience below is the universal widget — one <script> tag plus a target element — running entirely against the public API. Nothing here knows about the database.

Inline embed

A <div data-booking-key> renders the full flow in place.

<script src="/widget.js" defer></script> <div data-booking-key="pk_demo_booking_123"></div>

Popup button

A launcher button opens the same flow in a modal overlay.

<div data-booking-key="pk_demo_booking_123" data-booking-mode="popup" data-booking-label="Book an appointment"></div>
